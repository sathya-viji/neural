Connected services

Services give the AI things it can do. Built-in services run inside the kernel. Add any MCP server in services.json, using the same format as other MCP apps. Secrets can be referenced as "vault:NAME" so they never sit in the file.

{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "vault:github.token" }
    }
  }
}
