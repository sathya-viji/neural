What would you like done?

Say what you want. The AI works out the steps; the kernel checks each one against your permissions and asks you before anything important happens.

Activity

Every action the AI proposed, what the kernel decided, and who approved it. Each record is linked to the one before, so changes to the history can be detected.

Permissions

You decide what the AI may do. Allow runs without asking, Ask needs your OK each time, Block is never allowed. Defaults: reading is allowed; changing or sending things asks first.

Capabilities

Services

Services give the AI things it can do. Built-in services run inside the kernel. Add any MCP server in services.json, using the same format as other MCP apps. Secrets can be referenced as "vault:NAME" so they never sit in the file.

{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "vault:github.token" }
    }
  }
}

Model

Models are replaceable. A local model keeps everything on this computer. A cloud model is more capable, but your request and the results of each step are sent to its provider.
